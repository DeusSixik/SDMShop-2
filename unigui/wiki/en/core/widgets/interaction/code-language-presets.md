# CodeLanguagePresets

Factory registry supplying tokenizers and validators for language presets.

## Overview

`CodeLanguagePresets` provides static helper methods to apply preconfigured tokenizer and validator pipelines to a `CodeEditor`.

**Apply Preset**

Applies tokenizer, validator, and styles corresponding to language preset.
