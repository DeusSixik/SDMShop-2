# CodeLanguagePreset

Enumeration of built-in language presets for syntax highlighting and validation.

## Overview

`CodeLanguagePreset` defines standard language identifiers (such as `XML`, `JSON`, `GLSL`, `JAVASCRIPT`) configured with default tokenizers and styles.
