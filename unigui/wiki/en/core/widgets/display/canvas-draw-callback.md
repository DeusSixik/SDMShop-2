# CanvasDrawCallback

Functional interface for drawing custom 2D graphics into a [CanvasWidget](<../../../widgets/display/canvas-widget.md>).

## Overview

`CanvasDrawCallback` receives `RenderContext` when a `CanvasWidget` renders its content pass.
