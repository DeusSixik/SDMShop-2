# NodeGraphRegionSnapshot

Serializable region state containing its label, comment, color, bounds, and interaction flags.

## Overview

A `NodeGraphRegionSnapshot` stores a region's world-space geometry and presentation state for graph persistence. It contains no widgets and can be included alongside item and connection snapshots when saving a graph.
