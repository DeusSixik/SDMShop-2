# PortRowModule

Standard modular node row for input/output ports, labels, flow pins, and inline input editors.

## Overview

Use `PortRowModule` for data inputs and outputs or an execution-flow row. An inline default-value editor is visible only while its input is unconnected. The module creates its ports when attached to a node and applies the graph's connection-capacity rules.
