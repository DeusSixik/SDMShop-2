# RerouteModule

Compact pass-through node module for bending and branching graph wires.

## Overview

Insert a reroute into a wire to route it around other nodes or create a branch point. Data reroutes accept data types, while flow reroutes accept only execution-flow connections. `NodeGraph` registers the built-in reroute node types automatically.
