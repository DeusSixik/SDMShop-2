# SeparatorModule

Small horizontal divider module for separating groups of rows inside a node.

## Overview

Add a `SeparatorModule` between node sections to provide a thin visual divider. It has fixed height and does not create widgets or ports; `NodeBuilder.separator()` adds it to a modular node.
