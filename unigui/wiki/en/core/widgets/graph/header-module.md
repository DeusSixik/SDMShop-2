# HeaderModule

Standard modular node title bar with an icon, title, and collapse control.

## Overview

Place a `HeaderModule` first in a modular node to provide its title bar. It uses the node's header style and remains visible while the node is collapsed. Add execution pins in a `PortRowModule.flow(...)` below the header.
