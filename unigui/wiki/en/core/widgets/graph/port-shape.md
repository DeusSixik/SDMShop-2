# PortShape

Marker geometries used to distinguish port types on the graph canvas.

## Overview

Choose a `PortShape` when defining a `PortType`: circles commonly mark data, squares mark execution flow, diamonds mark collections, and triangles mark delegates or events. [Shape](<../../../widgets/display/shape.md>) complements the port color so types remain distinguishable at a glance.
