# NodeGraphAlign

Alignment modes for arranging selected node items against their shared bounds.

## Overview

Pass a `NodeGraphAlign` value to the graph alignment command to align selected nodes by a shared edge or center axis. Alignment uses the combined bounds of the selection and preserves each node's size.
