# GraphIssue

Validation diagnostic with severity, affected node and optional port, and a user-facing message.

## Overview

`GraphIssue` represents one warning or error found by static validation or executor checks. Use its severity to decide whether execution is blocked, and its item and port ids to focus or annotate the relevant part of the editor.
