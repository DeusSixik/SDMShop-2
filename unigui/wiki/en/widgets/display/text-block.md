# TextBlock

Multiline paragraph text display widget supporting line wrapping, line height, and text alignments.

## Overview

`TextBlock` is optimized for displaying longer narrative paragraphs, documentation excerpts, and multi-line descriptions with configurable line spacing and paragraph alignment.

## Paragraph TextBlock

```java
TextBlock paragraph = new TextBlock()
        .text("UniGUI provides modern, hardware-accelerated UI rendering for Minecraft.")
        .wrap(true);
```
