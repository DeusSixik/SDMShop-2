# ImageView

Texture display widget presenting static images, icons, or animated sprites with scale modes.

## Overview

`ImageView` extends `TextureWidget` as a dedicated image display component with declarative XML attributes and styling integration.

## Image [View](<../containers/view.md>) Example

```java
ImageView logo = new ImageView(TextureHandle.of("mod:textures/gui/logo.png"));
```
