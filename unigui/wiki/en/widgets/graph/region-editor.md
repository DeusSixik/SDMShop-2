# RegionEditor

Floating overlay editor for a graph region title or multiline comment.

## Overview

`RegionEditor` provides focused inline editing for region labels. It must be hosted by an `OverlayLayer`; Enter applies a title, Ctrl+Enter applies a comment, and Escape cancels. Clicking outside applies the current value so edits are not silently lost.
