# TextField

Standard user-facing single-line editable text field component.

## Overview

`TextField` is the concrete consumer-facing single-line text input widget in UniGUI. It wraps `TextInput` with standardized styling and default paddings.

## Standard TextField

```java
TextField emailField = new TextField()
        .placeholder("user@example.com");
```
