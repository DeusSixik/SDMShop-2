# PortTypeRegistry

Каталог типов портов с цветами, формами и направленными правилами совместимости типов данных.

## Обзор

Настройте `PortTypeRegistry` до создания узлов. Зарегистрируйте используемые типы данных и потока, затем задайте разрешённые направленные преобразования, например из `int` в `float`. Неизвестные ID разрешаются в нейтральный тип `any`; потоковые соединения проверяются отдельно от преобразований данных.
