# GraphValidator

Статические проверки обязательных входов, циклов чистых data-узлов и недостижимых исполняемых узлов.

## Обзор

Используйте `GraphValidator`, чтобы найти структурные проблемы до запуска графа. Проверяются обязательные входы, циклы данных между чистыми узлами и недостижимые exec-узлы; результат содержит элементы `GraphIssue` с важностью и ссылками на узел или порт. `GraphExecutor.validate` дополнительно проверяет регистрацию поведений.
