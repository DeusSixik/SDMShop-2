# GraphIssue

Диагностика проверки графа с уровнем важности, затронутым узлом и необязательным портом.

## Обзор

`GraphIssue` представляет предупреждение или ошибку, найденную статической проверкой или исполнителем. По уровню важности определите, блокируется ли запуск; ID элемента и порта позволяют сфокусировать или отметить соответствующее место редактора.
