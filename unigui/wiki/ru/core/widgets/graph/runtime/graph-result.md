# GraphResult

Результат исполнения графа: число шагов и последние выходные значения исполняемых узлов.

## Обзор

`GraphResult` возвращается вызовом `GraphExecutor.fire`. Используйте `steps()` для числа выполненных шагов и `output(nodeId, portId)` для чтения последнего значения, опубликованного исполняемым узлом. Значения чистых узлов вычисляются по запросу и не включаются в карту выходов.
