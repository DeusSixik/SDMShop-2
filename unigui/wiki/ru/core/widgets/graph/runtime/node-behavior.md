# NodeBehavior

Функциональный контракт вычисления значений узла или выполнения шага потока.

## Обзор

Создавайте чистые поведения через `NodeBehavior.pure(...)` для детерминированных вычислений и исполняемые через `NodeBehavior.exec(...)` для событий и побочных эффектов. Поведение получает `NodeContext` для чтения входов, публикации выходов и выбора продолжений потока; зарегистрируйте его в `GraphExecutor` по ID типа узла.
