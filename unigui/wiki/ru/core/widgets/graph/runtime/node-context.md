# NodeContext

Контекст исполнения без UI для чтения входов узла, публикации выходов и управления потоком.

## Обзор

`NodeContext` доступен только во время выполнения `NodeBehavior`. Читайте связанные значения или значения редакторов по умолчанию через типизированные методы, публикуйте результаты через `output`, а продолжение выбирайте через `continueWith` или `runFlow`. Чистым поведениям не следует хранить состояние между вызовами.
