# GraphModel

Неизменяемый снимок графа без виджетов: узлы, порты, значения входов и связи для проверки или исполнения.

## Обзор

Получите модель вызовом `NodeGraph.model()`, чтобы отделить исполнение от UI редактора. Снимок можно проверять, исполнять и тестировать без отрисовки виджетов. Последующие изменения исходного графа не меняют модель, поэтому после редактирования создавайте новый снимок.
