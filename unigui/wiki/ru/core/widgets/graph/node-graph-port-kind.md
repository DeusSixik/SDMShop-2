# NodeGraphPortKind

Направление соединения для порта узла: INPUT, OUTPUT или BIDIRECTIONAL.

## Обзор

Направление соединения для порта узла: INPUT, OUTPUT или BIDIRECTIONAL. Предоставляет широкие возможности настройки компоновки и взаимодействия.
