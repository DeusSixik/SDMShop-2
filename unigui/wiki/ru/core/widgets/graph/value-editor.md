# ValueEditor

Контракт типизированного редактора значения по умолчанию входа узла: UI, доступ к значению и сериализация.

## Обзор

Реализуйте `ValueEditor`, если вход узла требует пользовательского редактора или типа значения. Редактор владеет виджетом и предоставляет runtime-значение независимо от виджета. Сериализованное представление должно проходить цикл `serialize()` и `deserialize()`, чтобы снимки, копирование и восстановление сохраняли значения по умолчанию.
