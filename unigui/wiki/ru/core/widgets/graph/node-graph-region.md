# NodeGraphRegion

Перемещаемая и изменяемая область-комментарий для группировки узлов на холсте графа.

## Обзор

Создайте область через `NodeGraph.addRegion`, чтобы подписать и визуально сгруппировать часть холста. Её геометрия перемещается вместе с областью просмотра; узлы, целиком находящиеся внутри, следуют за областью при перетаскивании заголовка. Тело пропускает события указателя, интерактивны только заголовок и угол изменения размера.
