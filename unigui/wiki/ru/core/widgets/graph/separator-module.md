# SeparatorModule

Небольшой модуль горизонтального разделителя между группами строк узла.

## Обзор

Добавьте `SeparatorModule` между секциями узла, чтобы визуально разделить их тонкой линией. У него фиксированная высота, он не создаёт виджеты или порты; `NodeBuilder.separator()` добавляет разделитель в модульный узел.
