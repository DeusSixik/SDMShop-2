# PortRowModule

Стандартная строка модульного узла для портов, подписей, потоковых пинов и inline-редакторов.

## Обзор

Используйте `PortRowModule` для data-входов и выходов либо строки потока выполнения. Inline-редактор значения по умолчанию виден, пока вход не подключён. Модуль создаёт порты при присоединении к узлу и соблюдает правила ёмкости соединений графа.
