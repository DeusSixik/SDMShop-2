# NodeGraphAlign

Режимы выравнивания выбранных элементов графа по общим границам.

## Обзор

Передайте значение `NodeGraphAlign` команде выравнивания, чтобы расположить выбранные узлы по общей границе или центральной оси. Выравнивание использует общие границы выделения и сохраняет размеры каждого узла.
