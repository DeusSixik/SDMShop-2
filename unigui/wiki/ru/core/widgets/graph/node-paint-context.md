# NodePaintContext

Контекст рисования и состояния узла для отрисовки фона пользовательского модуля.

## Обзор

`NodePaintContext` передаётся в `NodeModule.paintBackground`. Он предоставляет активную область рисования, узел и его стиль, а также состояние наведения и выделения. Преобразуйте локальные координаты и длины через `x`, `y` и `scale`; эти методы учитывают текущий зум графа.
