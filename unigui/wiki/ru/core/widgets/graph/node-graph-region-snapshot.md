# NodeGraphRegionSnapshot

Сериализуемое состояние области: заголовок, комментарий, цвет, границы и флаги взаимодействия.

## Обзор

`NodeGraphRegionSnapshot` хранит геометрию области в world-координатах и её визуальное состояние для сохранения графа. Снимок не содержит виджетов и может сохраняться вместе со снимками узлов и соединений.
