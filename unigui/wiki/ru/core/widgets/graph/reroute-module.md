# RerouteModule

Компактный сквозной модуль-узел для изгиба и ветвления проводов графа.

## Обзор

Вставьте reroute в провод, чтобы обвести другие узлы или создать точку ветвления. Data-reroute принимает типы данных, а flow-reroute — только поток выполнения. `NodeGraph` автоматически регистрирует встроенные типы reroute.
