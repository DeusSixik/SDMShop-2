# HeaderModule

Стандартная полоса заголовка модульного узла с иконкой, названием и управлением сворачиванием.

## Обзор

Добавьте `HeaderModule` первым модулем, чтобы задать узлу заголовок. Он использует стиль заголовка узла и остаётся видимым в свёрнутом состоянии. Потоковые пины располагайте в `PortRowModule.flow(...)` сразу под заголовком.
