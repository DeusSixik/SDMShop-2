# PortShape

Формы маркеров, различающие типы портов на холсте графа.

## Обзор

Выберите `PortShape` при определении `PortType`: круг обычно обозначает data-порт, квадрат — поток выполнения, ромб — коллекцию, треугольник — делегат или событие. Форма дополняет цвет порта и помогает быстро различать типы.
