# ValueEditors

Фабрика готовых редакторов значений для распространённых типов входов узла.

## Обзор

Используйте `ValueEditors` для создания текстовых, числовых, целочисленных, логических, цветовых, списочных и векторных значений по умолчанию для входов `NodeBuilder`. Каждый редактор предоставляет типизированное runtime-значение и стабильное текстовое представление; векторы используют `double[]`, а цвета — целые ARGB.
