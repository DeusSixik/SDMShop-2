# NodeType

Повторно используемое описание вида узла: идентификатор, метаданные палитры, эскизы портов и фабрика.

## Обзор

`NodeType` описывает, что представляет собой узел, независимо от его положения. Регистрируйте типы в `NodeTypeRegistry`, чтобы заполнить палитру добавления и поддержать восстановление снимка. Фабрика должна возвращать новый `NodeGraphItem` для каждого запрошенного ID; идентификатор типа назначается созданному элементу.
