# NodeTypeRegistry

Каталог типов узлов для палитры, поиска и восстановления модульных элементов графа.

## Обзор

Зарегистрируйте каждый повторно используемый `NodeType` и передайте общий реестр графу и палитре узлов. Реестр обеспечивает поиск по ID, перечисление в порядке регистрации, группировку категорий и ранжированный регистронезависимый поиск. Повторная регистрация существующего ID заменяет прежнее описание.
