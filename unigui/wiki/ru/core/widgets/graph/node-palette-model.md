# NodePaletteModel

Модель без виджетов для просмотра категорий, ранжированного поиска, выбора и прокрутки палитры узлов.

## Обзор

Используйте `NodePaletteModel` при создании собственной палитры узлов или тестировании её поведения без отрисовки виджетов. Пустой запрос показывает сворачиваемое дерево категорий, непустой — отфильтрованный ранжированный список. Перемещение выбора зациклено, а видимая область следует за выбранной записью.
