# WidgetModule

Модуль узла, встраивающий произвольный виджет отдельной строкой на всю ширину.

## Обзор

Используйте `WidgetModule`, чтобы встроить превью, слайдер или редактор без реализации собственного `NodeModule`. Виджет растягивается по ширине узла; высота строки определяется предпочтительным размером или заданным минимумом. Текстовые редакторы имеют стабильные размеры, поэтому ввод текста не меняет размер узла.
