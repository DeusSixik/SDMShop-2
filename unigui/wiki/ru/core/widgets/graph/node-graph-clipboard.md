# NodeGraphClipboard

Неизменяемый буфер выбранных зарегистрированных типов узлов и внутренних соединений для копирования.

## Обзор

`NodeGraphClipboard` — данные, которые передаются при копировании и вставке графа. Включаются только модульные узлы с зарегистрированным `NodeType` и соединения, оба конца которых также скопированы. Сохраняются значения редакторов входов и поддерживаемое состояние; пользовательские виджеты содержимого создаются фабрикой типа в целевом графе.
