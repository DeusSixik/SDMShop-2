# NodeGraphHistory

История undo/redo изменений графа, сгруппированных в именованные транзакции.

## Обзор

`NodeGraphHistory` записывает обратимые операции, выполненные внутри транзакции. Объединяйте связанные программные изменения вызовом `NodeGraph.transact(name, action)`, чтобы они отменялись одним шагом. Граф сам открывает транзакции для основных интерактивных действий; изменения вне транзакции намеренно не записываются.
