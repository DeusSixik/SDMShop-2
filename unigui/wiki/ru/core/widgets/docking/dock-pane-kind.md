# DockPaneKind

Классификация панели докинга: DOCUMENT (основное содержимое рабочей области) или TOOL (вспомогательное инструментальное окно).

## Обзор

`DockPaneKind` классифицирует панели внутри компоновки IDE.

| Тип | Назначение |
| --- | --- |
| `DOCUMENT` | Основные документы редактора (файлы кода, холст, диаграммы), занимающие центральную часть рабочей области. |
| `TOOL` | Вспомогательные боковые панели (обозреватель проекта, консоль, терминал, инспектор), пристыкованные по краям. |

- [DockingRoot](<../../../widgets/docking/docking-root.md>): Корневой визуальный виджет системы докинга IDE, объединяющий узлы дерева, полосы вкладок, разделители, предпросмотр сброса и отрыв в плавающие окна.
