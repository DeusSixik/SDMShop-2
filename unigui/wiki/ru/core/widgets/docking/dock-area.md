# DockArea

Целевая зона назначения для операций докинга: краевые разделения (LEFT, RIGHT, TOP, BOTTOM), группировка во вкладки (CENTER, TAB) или плавающие окна (FLOAT).

## Обзор

`DockArea` указывает целевую область пристыковки панели в существующую раскладку.

### Области докинга

| DockArea | Действие | Изменение узла |
| --- | --- | --- |
| `CENTER` / `TAB` | Группировка во вкладки | Добавляет панель в существующий листовой узел в виде новой вкладки. |
| `LEFT` | Горизонтальный сплит | Разделяет область: новая панель слева, существующая справа. |
| `RIGHT` | Горизонтальный сплит | Разделяет область: существующая панель слева, новая справа. |
| `TOP` | Вертикальный сплит | Разделяет область: новая панель сверху, существующая снизу. |
| `BOTTOM` | Вертикальный сплит | Разделяет область: существующая панель сверху, новая снизу. |
| `FLOAT` | Отдельное окно | Отрывает панель в независимое плавающее окно. |

### <span class="api-class-prefix">DockArea::</span>`insertsBeforeTarget()` {: #insertsbeforetarget data-toc-label="insertsBeforeTarget()" }

Проверяет, разделяет ли данная область докинга пространство перед опорной панелью (LEFT, TOP).

Возвращает `boolean`: True, если докинг в эту область делит пространство перед целевой панелью; иначе false..
