# CodeDiagnostic

Запись диагностики, представляющая ошибку, предупреждение или подсказку в заданном диапазоне кода.

## Обзор

`CodeDiagnostic` содержит уровень важности (ошибка/предупреждение), текстовое сообщение, номер строки, колонку и смещения символов для отрисовки волнистых линий и подсказок.
