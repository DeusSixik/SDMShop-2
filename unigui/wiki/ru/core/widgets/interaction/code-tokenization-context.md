# CodeTokenizationContext

Контекстная запись, передаваемая токенизаторам, содержащая исходный текст и идентификатор языка.

## Обзор

`CodeTokenizationContext` предоставляет входную строку и целевой идентификатор языка при синтаксическом разборе.
