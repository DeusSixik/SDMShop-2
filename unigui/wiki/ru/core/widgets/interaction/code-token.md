# CodeToken

Неизменяемый токен диапазона символов, связывающий индексы с визуальным стилем [TokenStyle](<token-style.md>).

## Обзор

`CodeToken` хранит `startIndex`, `endIndex` и объект `TokenStyle`, задающий цвет шрифта и оформление выделенного участка кода.
