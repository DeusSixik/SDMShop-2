# CodeLanguagePreset

Перечисление встроенных пресетов языков для подсветки синтаксиса и валидации.

## Обзор

`CodeLanguagePreset` определяет идентификаторы поддерживаемых языков (таких как `XML`, `JSON`, `GLSL`, `JAVASCRIPT`), для которых доступны готовые токенизаторы и стили.
