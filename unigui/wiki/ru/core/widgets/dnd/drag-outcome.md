# DragOutcome

Описывает конечный результат жеста drag-and-drop в UniGUI: успешный сброс, сброс без цели или отмена.

## Обзор

`DragOutcome` описывает итоговый результат выполнения жеста drag-and-drop.

### Значения результата

| Значение | Описание |
| --- | --- |
| `DROPPED` | Передаваемые данные успешно сброшены в принявшую их зону сброса. |
| `NO_TARGET` | Указатель был отпущен над областью, где нет подходящей цели сброса. |
| `CANCELLED` | Операция перетаскивания была явно отменена или прервана. |

!!! note "Завершение жизненного цикла"
    Когда `DragController` вызывает `onDragEnd(Consumer<DragEnd>)`, объект `DragEnd` содержит данный результат, позволяя исходному виджету решить, удалять ли элемент, сбросить прозрачность или вернуть исходное состояние.
