# TextOverflowMode

Перечисление режимов обработки текста, превышающего доступные границы виджета (обрезка, многоточие, сжатие, бегущая строка).

## Обзор

`TextOverflowMode` управляет визуальным поведением текста при выходе за пределы выделенного виджету пространства. Влияет исключительно на отрисовку, не искажая исходный текст или базовые метрики компоновки.

## Режимы переполнения

- `VISIBLE`: Текст отображается полностью и может выходить за границы виджета.
- `CLIP`: Жёсткая обрезка текста по прямоугольнику виджета (scissor clip).
- `ELLIPSIS`: Однострочный текст обрезается с добавлением многоточия (`...`), гарантируя размещение в границах.
- `SHRINK_TO_FIT`: Размер шрифта динамически уменьшается, чтобы текст поместился в строку.
- `MARQUEE_ON_HOVER`: В покое текст обрезан, а при наведении курсора плавно прокручивается (бегущая строка).

## Настройка обрезки с многоточием для метки

```java
LabelWidget label = new LabelWidget("Очень длинное название файла или предмета");
label.overflow(TextOverflowMode.ELLIPSIS);
```

## Включение бегущей строки при наведении

```java
LabelWidget trackName = new LabelWidget("Исполнитель - Очень длинное название трека (Remix)");
trackName.overflow(TextOverflowMode.MARQUEE_ON_HOVER);
```
