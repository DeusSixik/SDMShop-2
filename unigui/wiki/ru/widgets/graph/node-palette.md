# NodePalette

Поисковая overlay-палитра типов узлов для создания узлов в редакторе графа.

## Обзор

`NodePalette` показывает зарегистрированные типы узлов деревом категорий или ранжированным списком результатов поиска. Палитра размещается в `OverlayLayer`, открывается в координатах экрана и сообщает выбранный тип через `onPick`. Клавиатурная навигация поддерживает раскрытие категорий, выбор, активацию и закрытие по Escape.
