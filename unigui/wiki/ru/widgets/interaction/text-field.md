# TextField

Стандартное однострочное редактируемое текстовое поле.

## Обзор

`TextField` — стандартное однострочное поле ввода в UniGUI. Предоставляет готовую настройку `TextInput` с выверенными отступами и стилями.

## Стандартное поле

```java
TextField emailField = new TextField()
        .placeholder("user@example.com");
```
