# ImageView

Виджет отображения текстур, представляющий статические картинки, иконки или спрайты.

## Обзор

`ImageView` расширяет `TextureWidget` и служит специализированным компонентом для показа изображений с поддержкой стилей и декларативной разметки XML.

## Пример ImageView

```java
ImageView logo = new ImageView(TextureHandle.of("mod:textures/gui/logo.png"));
```
