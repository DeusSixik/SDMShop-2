# `UniScreenOverlayRender`

Static entry point for registering and managing overlays rendered on top of active GUI screens in UniGUI.

- **Purpose:** Binds Widget hierarchies or configured UniRenderLayer instances to the SCREEN_OVERLAY render target.

### USE WHEN

- Displaying overlays above Minecraft screens (recipe lookups, sidebars, pinned notifications, tooltips).

- **Related:** `UniRenderLayer`, `UniRenderTarget`, `UniRenderLayerRegistration`
