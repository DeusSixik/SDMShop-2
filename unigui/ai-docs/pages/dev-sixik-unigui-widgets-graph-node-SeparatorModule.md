# `SeparatorModule` (implements `NodeModule`)

Thin horizontal divider between groups of node rows.

- **Purpose:** Visually separates input and output sections of a node.

### USE WHEN

- Split a node body into labelled sections.

### CRITICAL RULES & GOTCHAS:

- Fixed height of 6 world units; no widgets or ports.

- **Related:** `NodeModule`, `NodeBuilder`
