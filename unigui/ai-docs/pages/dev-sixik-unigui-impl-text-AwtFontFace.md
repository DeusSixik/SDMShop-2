# `AwtFontFace` (implements `SdfGlyphProvider`)

AWT-backed implementation of FontFace and SdfGlyphProvider for standalone desktop and server-side execution.

- **Purpose:** Provides font rasterization and signed-distance-field glyph generation using java.awt.Font.

### USE WHEN

- Executing UniGUI in non-Minecraft or desktop environments.

- **Related:** `FontFace`, `DefaultFontRegistry`
