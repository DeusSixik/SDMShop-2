# `TextRun` (extends `Record`, implements `RichTextSpan`)

Homogeneously styled contiguous substring within a RichText instance.

- **Purpose:** Combines a text string with font face, pixel size, color, brush, tracking, and text transform.

### USE WHEN

- Inspecting individual styled segments of a RichText model.

- **Related:** `RichText`, `RichTextSpan`, `FontFace`, `TextBrush`
