# `TextBrush`

Procedural fill brush for styling text glyphs with solid colors, multi-color linear gradients, or custom shaders.

- **Purpose:** Allows rich visual fills on text without altering glyph geometry.

### USE WHEN

- Applying gradients or textured fills across RichText runs.

- **Related:** `SolidTextBrush`, `LinearGradientTextBrush`, `RichText`
