# `Button` (extends `SurfaceWidget`)

Interactive push button with composable surface, text, icon, and rich state transitions.

- **Purpose:** Primary button component in UniGUI for user actions, form submits, and toolbar triggers.

### USE WHEN

- Triggering actions on click, keypress, or gamepad activation.

- **Related:** `HoldButton`, `ToolButton`, `ToggleButton`, `SurfaceWidget`
