# `UniRenderTarget` (extends `Enum`)

Enumerates host graphic target stages where a UniRenderLayer can be attached.

- **Purpose:** Decouples render layer hooks between in-game HUD, screen overlays, and loading screens.

### USE WHEN

- Registering render layers to specific game rendering pipeline stages.

- **Related:** `UniHudRender`, `UniScreenOverlayRender`, `UniRenderLayer`
