# `UniRenderLayerRegistration` (implements `AutoCloseable`)

Active handle representing a registered HUD or overlay layer in UniGUI.

- **Purpose:** Allows dynamically enabling/disabling, changing priority, modifying visibility, and unregistering the layer.

### USE WHEN

- Managing the lifecycle and properties of an active UniRenderLayer.

- **Related:** `UniRenderLayer`, `UniHudRender`, `UniScreenOverlayRender`
