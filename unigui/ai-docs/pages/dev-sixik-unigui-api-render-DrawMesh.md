# `DrawMesh`

Triangle mesh holding indexed or sequential DrawVertex entries for custom geometry rendering.

- **Purpose:** Provides an immutable container for triangulated geometry (e.g. RibbonMesh, custom procedural shapes, graphs) passed to DrawScope#addMesh.

### USE WHEN

- Submitting arbitrary 2D triangulated meshes to the rendering pipeline.
- Consuming procedural geometry generated by RibbonMesh or external tesselators.

### CRITICAL RULES & GOTCHAS:

- Vertices are interpreted in sets of three forming individual triangles.
- Standard constructor copies vertices defensively; ofOwned reuses the provided list in hot paths without cloning.

- **Related:** `DrawVertex`, `RibbonMesh`, `DrawScope`, `DrawCommand`
