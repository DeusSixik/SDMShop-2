# `UiPostEffectUniforms`

Container for post-processing shader uniforms with static values and dynamic suppliers.

- **Purpose:** Allows binding animated properties (time, player stats, color pulses) without recreating pass objects.

### USE WHEN

- Configuring shader parameters on a UiPostEffectPass.

- **Related:** `UiPostEffectPass`, `ShaderUniforms`, `ShaderUniform`
