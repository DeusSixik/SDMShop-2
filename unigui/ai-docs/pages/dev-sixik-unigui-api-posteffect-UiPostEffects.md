# `UiPostEffects`

Standard catalog of built-in post-processing effects, GLSL shaders, and helper factory methods.

- **Purpose:** Provides presets for vignette, tint, scanline, barrel distortion, chromatic aberration, and passthrough.

### USE WHEN

- Applying common post-processing filters to UniRenderLayer or creating built-in effect chains.

- **Related:** `UiPostEffectChain`, `UiPostEffectDefinition`, `UiPostEffectRegistry`
