# `FontFace`

Font face abstraction providing glyph rasterization and typographic metrics (ascent, descent, line height).

- **Purpose:** Decouples text rendering and layout from underlying graphics APIs or desktop font systems.

### USE WHEN

- Measuring text bounds or configuring custom fonts for RichText and TextRun.

- **Related:** `FontMetrics`, `FontRegistry`, `RichText`, `TextEngine`
