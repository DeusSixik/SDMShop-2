# `UiPostEffectBlendMode` (extends `Enum`)

Enumerates framebuffer blending modes for post-processing passes (REPLACE, ALPHA_BLEND, ADDITIVE).

- **Purpose:** Informs the graphics backend whether alpha blending or additive equation should be applied.

### USE WHEN

- Configuring blend modes on a UiPostEffectPass.

- **Related:** `UiPostEffectPass`
