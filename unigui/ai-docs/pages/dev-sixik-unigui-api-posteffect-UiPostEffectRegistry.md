# `UiPostEffectRegistry`

Registry repository storing named post-effect definitions accessible by string identifier.

- **Purpose:** Acts as a central repository for built-in, modded, and StylePack post-processing effects.

### USE WHEN

- Registering custom effects or resolving effect pipelines by name.

- **Related:** `UiPostEffectDefinition`, `UiPostEffects`, `UiPostEffectChain`
