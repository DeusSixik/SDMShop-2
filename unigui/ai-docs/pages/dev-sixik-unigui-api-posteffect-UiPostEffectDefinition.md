# `UiPostEffectDefinition`

Immutable specification of a post-processing effect composed of ordered shader passes.

- **Purpose:** Allows defining reusable multi-pass effects that can be registered in UiPostEffectRegistry.

### USE WHEN

- Authoring custom post-processing effects in code or StylePacks.

- **Related:** `UiPostEffectPass`, `UiPostEffectRegistry`, `UiPostEffectChain`
